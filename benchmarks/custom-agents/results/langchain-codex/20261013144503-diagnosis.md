## Write a change

One file per idea under `sharpen/`, with the failure it fixes as `why`. Then run `hone sharpen`.

```ts
// sharpen/<what-it-does>.ts
import { change } from "hone-eval";

change("what it does", {
  why: "which failure mode above, and why this fixes it",
  text: "the new text",                 // a new version of the text above
  // config: (config) => ({ ...config }),  // or a change to the config: a setting, a model, new code
});
```

New code goes into a new file that the `config` function points at. Do not edit a file the current system runs: the comparison needs it unchanged.
