# T-303 Multiple comparisons and indistinguishable groups

## Goal
Rank several targets without fooling yourself: Holm-Bonferroni over all pairwise paired tests, then group targets that are not significantly different.

## API (`src/stats/holm.ts`)
- `holm(pValues: number[], alpha = 0.05)` -> `{ adjusted: number[], reject: boolean[] }` matching the `holm` vectors (step-down, monotone adjusted values capped at 1).
- `leaderboard(scores: Record<targetId, number[]> /* aligned by case */, alpha = 0.05)` -> `{ order: targetId[] (by mean desc), pairwise: { a, b, p, adjusted, significant }[], groups: targetId[][] }` where groups are the maximal cliques of the "not significantly different" graph (Bron-Kerbosch on at most a few dozen nodes), each sorted by mean.
