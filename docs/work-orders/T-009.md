# T-009 Compatibility research

## Goal
Resolve the open questions from the architecture note so later tasks have exact formats. Output is one document, `docs/compat.md`, with a source URL and date on every claim.

## Questions
1. Harbor: task directory layout (instruction, tests, environment, solution), `harbor run` output directory layout and trajectory file format (ATIF or other), dataset registry naming. Source: https://github.com/harbor-framework/harbor and harborframework.com/docs.
2. verifiers v1 (Prime Intellect): Taskset and Harness class signatures, scoring decorator, `vf-eval` output location and fields. Source: https://github.com/PrimeIntellect-ai/verifiers (`docs/`, `skills/`).
3. OpenTelemetry GenAI semantic conventions: current span names, `gen_ai.operation.name` values, agent and tool attributes, message events. Source: https://github.com/open-telemetry/semantic-conventions-genai (`docs/`, `model/`). Record the commit hash read.
4. Docent (Transluce): license and whether self-hosting is possible; AgentRun JSON shape for ingestion. Source: https://github.com/TransluceAI/docent, https://docs.transluce.org.
5. Jev: documented or observed limits on questions per request and state size. Source: https://docs.typesafe.ai; if undocumented, measure with one small probe only if a key is configured, otherwise mark unknown.
6. Inspect `.eval` JSON schema: run `uvx --from inspect-ai inspect log schema` if available and store the schema under `test/fixtures/inspect.schema.json`; otherwise link the docs.

## Steps
Read the sources, write `docs/compat.md` with one section per question, each ending in a "Decision for hone" line that later tasks (T-107, T-704, T-803, T-802) can follow verbatim.

## Acceptance
- `docs/compat.md` exists with six sections, each with at least one dated source URL.
- No code changes.
