# T-206 LLM rubric judge

## Goal
A generative judge for cases Jev cannot express: free-form rubrics with explanations, dimension-split scoring, pairwise comparison with order swap.

## Scorers (`src/scorers/judge/llm.ts`)
- `llm.rubric` `{ rubric: string (or case.rubric), dimensions?: string[], scale = 5, state = "output" | "messages", unknownOption = true, temperature = 0 }`: prompt asks for JSON `{ dimensions: { <name>: { score, reason } }, overall, reason, verdict: "pass"|"fail"|"unknown" }` (single dimension when none given). `value` = overall / scale, `pass` = verdict pass/fail, `null` on unknown; `reason` = overall reason; `evidence` = per-dimension entries. Non-JSON replies retry once with a repair prompt, then score `null`.
- `llm.pairwise` `{ rubric, other: Target | TargetOutput provider, swap = true }`: compares the trial output with the other output; with `swap`, runs both orders and reports `tie` when they disagree; `value` = 1 win, 0.5 tie, 0 loss. The other output comes through `ScoreContext.runTarget`-like hook `ctx.runOther()` supplied by the caller (compare in P4); tests pass it directly.
- Shared prompt builder with the Anthropic guidance baked in: grade outcomes not step order, allow partial credit, offer Unknown, one dimension at a time.
- Uses `chat()` from T-008 with `json: true` for openai; for anthropic the prompt demands JSON and the parser strips code fences.
