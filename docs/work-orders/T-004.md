# T-004 Content-addressed cache

## Goal
A file cache keyed by the sha256 of a canonical JSON key, used for target outputs (T-402) and scorer results (T-207).

## API (`src/core/cache.ts`)
- `canonicalJson(value: unknown): string` sorts object keys recursively, no whitespace. Arrays keep order.
- `cacheKey(parts: unknown): string` = sha256 hex of `canonicalJson(parts)`.
- `class Cache { constructor(dir = ".hone/cache"); has(key); get<T>(key): T | undefined; set(key, value); memo<T>(key, fn: () => Promise<T>): Promise<T>; clear() }`. Files at `<dir>/<key[0:2]>/<key>.json` containing `{ key, storedAt, value }`. `set` writes atomically (temp file + rename).
- `get` of a corrupt file returns `undefined` and deletes it; never throws.
