# T-104 Process target (CLI coding agents)

## Goal
Run a CLI agent inside an isolated copy of a workspace, capture its transcript, git diff and cost, with presets for Claude Code, Codex, OpenCode and Aider plus a generic command.

## Spec `{ kind: "process", agent, workspace, isolate = "copy", timeoutMs = 600000, model?, env?, command?, promptFile? }`
- `agent: "claude-code" | "codex" | "opencode" | "aider" | "generic"`.
- `workspace`: directory to copy. `isolate`: `"copy"` (recursive copy to a temp dir, `.git` included if present, `node_modules` and `.hone` skipped), `"worktree"` (`git worktree add` of HEAD in a temp dir, removed on close), `"none"` (run in place).
- Baseline: if the isolated dir has no `.git`, run `git init && git add -A && git commit -m baseline` so a diff is always available.
- `input` is the prompt string (or `input.prompt`). Presets (argv arrays, `{prompt}`, `{model}`, `{workspace}` substituted):
  - claude-code: `claude -p {prompt} --output-format stream-json --verbose --permission-mode acceptEdits [--model {model}]`; parse NDJSON: `assistant` messages (text + `tool_use` blocks) to assistant messages with `tool_calls`, `user` messages with `tool_result` blocks to `tool` messages, final `result` message gives `output` (`result` text), `usage` and `total_cost_usd`.
  - codex: `codex exec --json {prompt} [--model {model}]`; parse NDJSON items best effort: `item.completed` with `agent_message` to assistant, `command_execution` to an assistant `tool_call` + `tool` result; last agent message is `output`; usage from `turn.completed`.
  - opencode: `opencode run --format json {prompt} [--model {model}]`; parse NDJSON `text`/`tool` parts similarly.
  - aider: `aider --message {prompt} --yes-always --no-auto-commits [--model {model}]`; stdout is the output, no structured messages.
  - generic: `command` (string[] with placeholders) is required; stdout is `output`; if stdout parses as JSON with `output|messages|spans|usage` keys, lift it.
- After the run: `artifacts.diff = git diff` (plus `git status --porcelain` untracked files appended as new-file diffs via `git add -N`), `artifacts.stdout`, `artifacts.stderr`. Each tool call also becomes a `tool` span; the whole run is one `agent` span.
- Timeout kills the process group and sets `error = "timeout"`; the executor turns that into the `timeout` flag.
- `version()`: sha256 of `{ agent, command, model, agent binary version (`<bin> --version`, cached per process) }`.
