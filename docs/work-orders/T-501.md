# T-501 TUI shell

## Goal
The terminal UI entry: `hone tui` (and plain `hone` in a TTY) opens a dashboard over the latest run, with a layout, keymap, theme and a state store fed by the run store. Built on OpenTUI 0.6 with the React reconciler.

## Facts (verified 2026-10-12 in a Bun 1.4.3 spike)
- Dependencies to add: `@opentui/core@0.6.0`, `@opentui/react@0.6.0`, `react@19.3.0` (runtime), plus `@types/react` (dev). OpenTUI requires bun >= 1.3.14.
- Render: `const renderer = await createCliRenderer({ exitOnCtrlC: true }); createRoot(renderer).render(<App/>)`. Components: `box` (border, title, flexDirection, width/height, padding), `text` (fg, `<span>`, `<strong>`), `scrollbox` (`focused`, style height), `input`, `select`, `tab_select`. Hooks: `useKeyboard((key) => key.name)`, `useRenderer()`, `useTerminalDimensions()`.
- Tests: `import { testRender } from "@opentui/react/test-utils"`; `const setup = await testRender(<App/>, { width, height })`; `await setup.renderOnce()`; `setup.captureCharFrame()` returns the screen as text; `setup.mockInput.pressKey("j")` simulates keys; always `setup.renderer.destroy()` in `finally`. React act warnings are harmless; wrap key presses in `act()` from `react` when they cause state updates.

## Design
- `src/tui/state.ts`: a tiny external store (`createTuiStore(store: Store, runId)` with `subscribe/getSnapshot` for `useSyncExternalStore`) holding `{ runId, cases, targets, cells (Verdict + trials), selected: { caseIdx, targetIdx }, screen: "matrix"|"trace"|"diff"|"clusters"|"calibrate"|"fork"|"candidates", trialIdx, help: boolean }` plus actions (`move`, `enter`, `back`, `setScreen`). A `watch` option re-reads the store every second (polling the sqlite index) so a running `hone run` in another terminal shows up.
- `src/tui/app.tsx`: root layout: header bar (run id, pass@1, cost, screen name), body (current screen), footer with the keymap for that screen. Global keys: `q` quit, `?` toggle help overlay, `esc` back, `1`..`6` jump screens, `r` reload.
- `src/tui/theme.ts`: color tokens (pass green, fail red, undecided grey, flag amber, accent steel blue) and `useTheme()`; respects `NO_COLOR`.
- `src/cli/commands/tui.ts`: `hone tui [--run id] [--watch]`; `hone` with no args in a TTY runs it, outside a TTY prints usage.
- `src/cli.ts`: the bundle for `bin` must keep running on Bun; document in README that the TUI needs Bun (other commands too, for now).
