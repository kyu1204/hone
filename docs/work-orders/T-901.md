# T-901 Five examples with passing suites

## Goal
Each example is a directory a newcomer can copy: a `hone.config.ts`, cases, and whatever the target needs, and every suite is green in CI with `hone ci`.

## Design (`examples/<name>/`, each with a `README.md` of under 40 lines)
- `qa-fn`: `fn` target answering arithmetic and lookup questions from `evals/cases.yaml`; scorers `exact`, `contains`, `consistency` (metamorphic rephrasing); gates `passAt1 >= 0.9`. Shows the simplest end-to-end loop.
- `rag-python`: `app.py` (standard library `http.server`, no pip) serving `POST /ask` over an in-memory chunk list and returning `{ answer, chunks }`; `hone.config.ts` with an `http` target whose `select` maps `chunks` to a retrieval span; scorers `rag.recall`, `rag.citations`, `rag.faithfulness` (skipped without a Jev key via `skipIf`) and a deterministic `contains`. The config starts the server itself in `targets.rag.start`/`stop` hooks if the http target supports them; otherwise the example test starts it.
- `agent-claude-code`: a `process` target (`agent: "claude-code"`) over `fixtures/repo` (a tiny Bun project with one failing test), scorers `test_command`, `hack`, `tool_used`; `evals/cases.yaml` has two tasks. In CI the `claude` binary is absent, so `hone.config.ts` falls back to a `replay` target over `fixtures/traces/*.json` when `process.env.CI` is set or `claude` is not on PATH, and the README explains the switch.
- `mcp-server`: `server.ts` is a 60-line stdio MCP server (tools `add`, `lookup`) written with Bun only; the `mcp` target calls `tools/call`; scorers `json-schema`, `exact`, `tool_used`.
- `harness-ablation`: a `fn` target whose behaviour depends on a rules text; `ablations` remove one rule each; `evolve: { seed, apply }` and `optimize: { ... }` hooks so `hone ablate`, `hone evolve --budget 1` (stub chat) and `hone optimize --budget 12` all run offline. Shows the correction commands.
- `examples/examples.test.ts`: for every example directory, run `ciCommand(["--quiet"], io)` with `cwd` set to it and assert exit 0; `rag-python` starts `app.py` on a free port first; `agent-claude-code` asserts the replay fallback is used when `claude` is missing. The test is part of `bun test`, so CI runs the suites.
- Configs import `defineConfig` and helpers from `../../src/index.ts` (in-repo); the READMEs show the `hone-eval` import a user would write.
