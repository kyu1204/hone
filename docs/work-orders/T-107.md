# T-107 Docker target (Harbor task directories)

## Goal
Run a Harbor-style task directory in a container: build the environment, run an agent command against `instruction.md`, run the verifier, read the reward. Format facts are in `docs/compat.md` section 1.

## Spec `{ kind: "docker", task: string, agentCommand: string[], timeoutMs = 1800000, buildTimeoutMs = 600000, keep = false }`
- `task`: directory with `task.toml`, `instruction.md`, `environment/Dockerfile`, `tests/test.sh` (and optional `solution/`). `task.toml` timeouts override the defaults when present.
- Build: `docker build -t hone-task-<hash> environment/`. Run: `docker run --rm -d` with `tests/` mounted read-only at `/tests`, a temp dir at `/logs`, `instruction.md` copied to `/instruction.md`, then `docker exec` the `agentCommand` (placeholders `{instruction_path}` and `{instruction}`), then `docker exec bash /tests/test.sh`, then read `/logs/verifier/reward.txt` (number) or `reward.json` (`{ rewards: Record<string, number> }`).
- Output: `output = reward` (number or rewards object), `artifacts.stdout/stderr` from both execs, `meta.taskName` from `task.toml`. If `/logs/agent/trajectory.json` exists after the run, map ATIF steps to messages (shared helper `src/io/atif.ts`, also used by T-802).
- `version()`: sha256 of the task directory file list + contents of `task.toml`, `instruction.md`, `environment/*`, `tests/*` and `agentCommand`.
- Missing docker binary: `TargetOutput.error = "docker not available"`.
