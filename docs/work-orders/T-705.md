# T-705 Reward server

## Goal
Serve the configured scorers over HTTP so a training loop or another tool can ask for a reward without importing hone.

## Design (`src/serve/reward.ts`)
- `startRewardServer({ scorers, port, host }) -> { port, host, stop }` using `Bun.serve`.
  - `GET /health` -> `{ ok: true, scorers: [names] }`.
  - `POST /score` body `{ messages?: ChatMessage[]; output?: unknown; case?: { id?: string; input?: unknown; expected?: unknown; rubric?: string }; spans?: Span[] }` -> builds a Trace (`toTrace` shape, ids generated, output defaulting to the last assistant content), runs every scorer with `runScorer`, responds `{ reward, pass, scores: Score[] }` where `reward` = 1/0 for pass/fail, mean score value when undecided.
  - `POST /batch` body `{ items: [...] }` -> `{ results: [...] }` in order; scorers run with concurrency 4.
  - 400 with `{ error }` on bad JSON or a body without `messages` and `output`; 500 with `{ error }` when a scorer throws.
- `hone serve reward [--port 8787] [--host 127.0.0.1] [--scorer name]...`: loads the config, selects scorers (all by default), logs one line per request to stderr. `serve.ts` dispatches `reward`; `mcp` stays reserved for T-706.
