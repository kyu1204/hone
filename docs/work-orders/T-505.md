# T-505 Clusters, Calibrate and Candidates screens

## Goal
Three read-mostly screens over analysis results that P6 and P7 produce.

## Design
- `src/tui/screens/clusters.tsx`: reads `.hone/taxonomy.json` and the latest `.hone/analysis/clusters-<runId>.json` (written by `hone cluster`, T-601/T-602). Left: failure codes with counts and a bar; right: the selected code's definition, evidence patterns and the list of trials; `enter` on a trial opens the trace screen. Empty state tells the user to run `hone cluster`.
- `src/tui/screens/calibrate.tsx`: reads `.hone/analysis/calibration-<judge>.json` (T-604): per fault type the detection rate with a Wilson interval as a bar, false alarms on clean runs, and kappa against human labels when present. Empty state: run `hone calibrate`.
- `src/tui/screens/candidates.tsx`: reads `.hone/evolve/<id>.json` (T-702) or `.hone/optimize/<id>.json` (T-703): candidates with pass@1, CI, cost, Pareto membership marked; `enter` shows the candidate's text diff against the baseline.
- All three use one `ListDetail` layout component (`src/tui/widgets/listDetail.tsx`) with `j/k`, `enter`, `esc`.
