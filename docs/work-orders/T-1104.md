# T-1104 `hone init` recognises LangChain and Strands projects

## Goal
In a project that depends on `langchain`, `langgraph` or `strands-agents`, `hone init` writes a config that already runs the agent.

## Design
- `detectProject` reads `pyproject.toml` and `requirements*.txt` for the three packages and adds a `python` target with a generated wrapper `hone_target.py` (`answer(input, ctx)` calling the user's agent factory, recording with `ctx.from_langchain` or `ctx.from_strands`), `params` with a `system_prompt`, and a `sharpen.text` block.
- The wrapper has one clearly marked line to edit: where the project's agent is built.
