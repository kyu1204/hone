# T-504 Diff screen

## Goal
Two trajectories side by side, aligned by tool-call sequence, with the first divergence highlighted, so "where did B go wrong compared to A" is one keypress away.

## Design (`src/tui/screens/diff.tsx`, alignment from `src/analysis/diffTrace.ts` of T-603; until T-603 lands, a local LCS over `role:toolName` signatures with the same signature `alignTraces(a, b) -> { pairs: [number|null, number|null][]; divergence: number | null }` lives in `src/tui/align.ts` and T-603 replaces it)
- Two `scrollbox` panes scrolling together; each row is an aligned pair: both messages (left/right), a gap on one side when unmatched. Rows before the divergence render muted; the divergence row is highlighted; rows after it are normal.
- Header: both trial ids, verdicts, costs, and "diverges at step k" or "identical sequence".
- Keys: `j/k` move, `n` jump to the divergence, `enter` expand both sides, `tab` swap sides, `esc` back.
- Entry points: matrix `d` on two cells; trace `D` compares the current trial with the previous trial of the same cell.
