# T-304 Power analysis

## Goal
Answer "how many cases do I need" and "what is the smallest difference I can detect" before spending money.

## API (`src/stats/power.ts`)
- `pairedPowerN({ effect, alpha = 0.05, power = 0.8 })` -> n (paired t, two-sided; solve by bisection on the noncentral t approximated with the normal-plus-correction used by statsmodels `TTestPower`: use `tTwoSidedP` and the noncentral t CDF via `regularizedIncompleteBeta`). Match the `power` vectors to 2 decimals in n (statsmodels uses a continuous n).
- `pairedMde({ n, alpha, power })` -> effect size (bisection on the same model).
- `withDesign(n, { pairingCorr?, repeats?, icc?, avgClusterSize? })` adjusts n: pairing shrinks variance by (1 - corr), repeats divide the decoding-noise part by repeats, clusters multiply by the design effect.
- `hone power` (T-410) formats the result; this task is the arithmetic only.
