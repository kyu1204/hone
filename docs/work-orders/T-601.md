# T-601 Failure clustering

## Goal
Group failed trials of a run so the failure modes with the most weight are visible first, and write the file the clusters screen reads.

## Design
- `src/providers/embed.ts`: `embed(texts: string[], opts?) -> Promise<number[][]>`. OpenAI-compatible `/embeddings` when `OPENAI_API_KEY` (or `HONE_EMBED_MODEL`, `OPENAI_BASE_URL`) is configured, model default `text-embedding-3-small`; otherwise `hashEmbed(texts)`: a 512-dim hashed bag of words (lowercased tokens, bigrams, L2-normalised) so clustering works offline. Both share one signature; the caller never knows which ran except through `meta.method`.
- `src/analysis/cluster.ts`:
  - `summarise(trial): string` = error, reasons of failed scorers, last assistant message (300 chars), tool names used, flags.
  - `kmeans(vectors, k, { seed, iterations = 30 })` with cosine distance and k-means++ seeding; `chooseK(n)` = `min(8, max(1, ceil(sqrt(n / 2))))`.
  - `clusterFailures(trials, { embed?, k?, seed? }) -> { clusters: { id, size, trialIds, representative, topTerms, summaries }[], method }`. Representative = trial closest to the centroid; top terms = highest mean TF-IDF tokens of the cluster against the others.
- `hone cluster [--run id] [--k n] [--json]`: writes `.hone/analysis/clusters-<runId>.json` in the T-505 shape with provisional codes `cluster-1..k` (`axis: "system"`, definition = top terms joined, evidencePatterns = top terms), prints a table (size, code, representative case, top terms). T-602 upgrades codes to an induced taxonomy.
