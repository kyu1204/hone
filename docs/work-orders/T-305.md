# T-305 Sequential stopping

## Goal
Stop sampling a case x target cell once its Wilson interval is narrow enough, bounded by a maximum, so adaptive runs spend trials where uncertainty is.

## API (`src/stats/sequential.ts`)
- `shouldStop({ successes, n, minTrials = 2, maxTrials, ciWidth, confidence = 0.95 })` -> `{ stop: boolean, reason?: "ci-width" | "max-trials", width }`.
- `nextCell(cells: { key, successes, n, maxTrials }[], ciWidth)` -> the cell with the widest interval that may still run (ties by fewer trials), or undefined when all stopped. The scheduler (T-401) calls this when `adaptive` is configured.
