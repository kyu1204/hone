# T-402 Executor

## Goal
Run one trial end to end: target (through the cache), trace, scorers (through the scorer cache), flags, pass verdict, store and events.

## API (`src/core/executor.ts`)
`createExecutor({ targets, scorers, cases, cache, store, events, gates, runId, useCache = true })` returns `execute(cell, trial): Promise<Trial>`:
1. `targetKey = cacheKey({ input: case.input, targetVersion: await target.version(), targetId })`. With `useCache`, `cache.memo(targetKey, () => run)`; a hit adds the `cached` flag. The cached entry stores `{ output, startedAt, endedAt }`. `ctx = { runId, caseId, trial, signal }`.
2. `trace = toTrace(output, ctx, targetId, startedAt, endedAt)`.
3. Scorers: each wrapped with `cachedScorer` when `useCache`; `ScoreContext.runTarget(input)` goes through the same cache so the consistency scorer benefits; scores collected with `runScorer` (never throws). `score:done` per scorer.
4. Flags: `reward-hack` when a scorer whose name starts with `hack` has `pass === false`; `timeout` when `trace.error === "timeout"`; `cached` as above.
5. `pass`: `false` if any score has `pass === false` or `trace.error` is set; `true` if at least one score has `pass === true` and none false; `null` otherwise. `gates.rewardHack === "fail"` forces `pass = false` when flagged; `"ignore"` drops the flag; `"warn"` (default) keeps the flag without changing pass.
6. `costUsd = trace.usage.costUsd + sum(score.costUsd)`. `store.saveTrial`; `trial:done` event with `cached`.
7. Target or scorer exceptions never escape: they become `trace.error` / null-pass scores.
