# T-302 Paired tests and clustered standard errors

## Goal
Compare two targets on the same cases the right way: paired differences, exact McNemar for binary outcomes, and cluster-robust SE when cases share a cluster.

## API (`src/stats/paired.ts`, `src/stats/cluster.ts`)
- `pairedDifference(a: number[], b: number[], confidence = 0.95)` -> `{ meanDiff, se, t, p, lo, hi, corr, n, varianceReduction }` (Student t with n-1 dof; `varianceReduction` = 1 - pairedVar / unpairedVar).
- `mcnemarExact(b: number, c: number)` -> `{ p, b, c }`: exact two-sided binomial test on discordant pairs (`min(1, 2 * P(X <= min(b,c)))` with X ~ Bin(b+c, 0.5)); p = 1 when b + c = 0.
- `cluster.ts`: `clusterRobustSe(values, clusters)` (CR1 sandwich, match the vector), `intraclassCorrelation(values, clusters)`, `designEffect(icc, avgClusterSize)`, `withinBetweenVariance(values, questionIds)`.
- `compareTargets(rows: { caseId, a: number, b: number, cluster?: string }[])` -> paired summary plus McNemar when both columns are binary, plus cluster-robust paired SE when clusters are present.
