# T-005 Run store

## Goal
Persist runs and trials as JSON under `.hone/runs/`, with a rebuildable `bun:sqlite` index for queries.

## Layout
- `.hone/runs/<runId>/run.json` (Run), `.hone/runs/<runId>/trials/<trialId>.json` (Trial).
- `.hone/index.sqlite`: tables `runs(id, created_at, config_hash, summary_json)`, `trials(id, run_id, case_id, target_id, trial, pass, cost_usd, flags_json, scores_json)`. Indexes on `(run_id)`, `(case_id, target_id)`.

## API (`src/core/store.ts`)
- `class Store { constructor(root = ".hone"); createRun(run: Omit<Run,"id"|"createdAt">): Run; saveTrial(trial: Trial): void; getRun(id): Run | undefined; listRuns(limit = 50): Run[]; getTrial(id): Trial | undefined; queryTrials(q: { runId?; caseId?; targetId?; pass? }): Trial[]; finishRun(id, summary): void; rebuildIndex(): void }`.
- `rebuildIndex()` drops the sqlite file and re-reads every JSON file. Opening a store whose sqlite is missing triggers a rebuild automatically.
- Run ids: `<ISO timestamp with ':' replaced by '-'>-<4 hex>`. Trial ids: `<runId>/<caseId>/<targetId>/<trial>` with `/` replaced by `_`.
