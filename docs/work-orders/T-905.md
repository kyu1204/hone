# T-905 v0.1.0: tag, npm publish, launch posts

## Goal
Ship v0.1.0 and tell people.

## Design
- `CHANGELOG.md` with a `## 0.1.0` section grouped by the plan phases (what exists, what is deferred: Kitty pixel charts inside the OpenTUI layout).
- `package.json` version `0.1.0`; `bun run release:check` passes; tag `v0.1.0` pushed; `release.yml` publishes. Publishing requires the npm trusted-publishing link the maintainer sets up once (T-903 docs); if it is not configured the loop marks this task `BLOCKED: npm trusted publishing not configured` and leaves the tag unpushed.
- Launch drafts in `docs/launch/`: `hn.md` (Show HN title + first comment), `x.md` (thread of 5), `awesome.md` (one-line entries for awesome-llm-eval style lists with the PR links to open). Posting is done by a human; the task ends when the drafts exist and the release is live.
- Post-release: README badge switches from "in progress" to the npm version badge only.

## TDD steps
1. `scripts/release-check.ts` is the test; it must pass before tagging.
2. Write CHANGELOG and drafts; bump; tag; verify `npm view hone-eval version` and the GitHub Release assets; update the README badge.
