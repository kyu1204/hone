# T-106 Replay target

## Goal
Re-score existing traces without calling anything: imported logs or past runs act as a Target.

## Spec `{ kind: "replay", traces: string | string[] | Trace[], select = "trial" }`
- Strings are globs of `*.json` (one Trace or an array) or `*.jsonl`; files are validated with `assertTrace`.
- `run(input, ctx)`: picks traces with `caseId === ctx.caseId`; `select: "trial"` returns the one whose `trial === ctx.trial` (falls back to index modulo count), `"random"` samples. No match: `TargetOutput.error = "no replay trace for case <id>"`.
- Returned `TargetOutput` carries the trace's `output`, `messages`, `spans`, `artifacts`, `usage` and `meta.replayedFrom = <trace id>`.
- `version()`: sha256 of sorted `(path, size, mtime)` or of inline trace ids.
