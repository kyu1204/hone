# T-507 Charts

## Goal
Numbers people can see: sparklines for pass@1 over runs, a Pareto scatter of cost vs pass@1 per target, and bars for intervals. Character cells everywhere; pixel graphics when the terminal supports the Kitty protocol.

## Design (`src/tui/widgets/chart.ts` pure functions + `src/tui/screens/charts.tsx`)
- `sparkline(values, width)` using the 8 block characters; `braillePlot(points, width, height)` for the scatter; `bar(value, lo, hi, width)` drawing the interval around the point.
- `detectGraphics()` reads `TERM`, `TERM_PROGRAM` and `KITTY_WINDOW_ID` to decide between `cells` and `kitty`; with `kitty`, the Pareto plot is rendered as a PNG drawn with a tiny rasteriser (no dependency; axes, points, labels) and emitted through the Kitty graphics escape (`\x1b_G...`) with a one-line fallback when the terminal does not acknowledge within 200ms.
- Charts screen: top: pass@1 sparkline across the last 20 runs of the same config hash; middle: Pareto scatter with target labels; bottom: per-target interval bars.
