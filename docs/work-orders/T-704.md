# T-704 Rollouts export

## Goal
Turn stored trials into RL-ready JSONL that TRL/verifiers-style trainers consume: prompt, completion (or trajectory), reward, info.

## Design (`src/io/export/rollouts.ts`)
- `toRollout(trial, opts?) -> Rollout` with `{ prompt: ChatMessage[]; completion: ChatMessage[]; reward: number; info: { trialId, runId, caseId, targetId, trial, pass, scores: { scorer, value, pass }[], flags, costUsd, injectedFault? } }`. `prompt` = messages up to and including the last user message that precedes the first assistant message (system included); `completion` = the rest (full trajectory, tool calls and results). `reward` = `pass === true ? 1 : pass === false ? 0 : mean(score.value)` unless `opts.reward` is `"mean-score"` (mean of score values) or a scorer name (that scorer's value).
- `writeRollouts(trials, out, opts)` streams one JSON object per line; `opts.passOnly` keeps `pass === true`; `opts.format` `"trl"` (default, fields above) or `"openai"` (`{ messages: [...prompt, ...completion], reward, info }`).
- `hone export rollouts [--run id] [--out rollouts.jsonl] [--pass-only] [--reward pass|mean-score|<scorer>] [--format trl|openai]`. `hone export` is a new command group; other formats arrive with T-803 and must print `not yet available` and exit 2 until then.
