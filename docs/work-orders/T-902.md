# T-902 README demo and docs pages

## Goal
A reader understands hone in two minutes from the README alone and can reach every doc from it.

## Design
- `.github/assets/demo.tape`: a VHS script (`vhs demo.tape` renders `demo.gif`): `hone run` on `examples/qa-fn`, `hone matrix`, `hone cluster`, open `hone` and move through matrix, trace and diff. `scripts/demo.sh` runs vhs when installed and prints the install hint otherwise. The gif is committed when it can be produced locally; the README embeds `.github/assets/demo.gif` either way (alt text describes the flow).
- README: "What it looks like" shows the gif plus three real command outputs captured from the examples (matrix table, cluster table, evolve verdict). "How it compares" table rechecked against the research note. "Quick start" uses the actual commands that exist now (including `hone import claude-code`). Links: docs, examples, skill, work orders.
- `docs/README.md`: an index of the docs pages with one line each; `docs/concepts.md`: the data model (Target, Case, Trial, Trace, Score, Verdict), caching, the correction loop diagram in ASCII.
- A link check: `scripts/check-links.ts` resolves every relative Markdown link in README.md, docs/**, examples/**/README.md to a file on disk; `scripts/check-links.test.ts` runs it.
