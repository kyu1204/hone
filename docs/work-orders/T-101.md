# T-101 Target interface, registry and HTTP target

## Goal
The `Target` contract every adapter implements, a registry that builds targets from config specs, and the first adapter: HTTP.

## Contract (`src/targets/target.ts`)
```ts
export interface RunContext { runId: string; caseId: string; trial: number; workspace?: string; signal?: AbortSignal; prefix?: ChatMessage[] }
export interface TargetOutput {
  output: unknown; messages?: ChatMessage[]; spans?: Span[]; artifacts?: Artifacts;
  usage?: Partial<Usage>; error?: string; meta?: Record<string, unknown>;
}
export interface Target {
  readonly id: string; readonly kind: string;
  version(): Promise<string>;                       // content hash used in cache keys
  run(input: unknown, ctx: RunContext): Promise<TargetOutput>;
  resume?(prefix: ChatMessage[], input: unknown, ctx: RunContext): Promise<TargetOutput>;  // added by T-108
  close?(): Promise<void>;
}
export function toTrace(out: TargetOutput, ctx: RunContext, targetId: string, startedAt: Date, endedAt: Date): Trace
```
`toTrace` fills `id` (= `Store.trialId`), `caseId`, `targetId`, `trial`, timestamps, defaults (`messages: []`, `spans: []`, `usage` zeros) and runs `assertTrace`.

## Registry (`src/targets/index.ts`)
`registerTargetKind(kind, factory: (id, spec) => Target)` and `createTarget(id, spec: TargetSpec): Target`. Unknown kind throws with the list of known kinds. `createTargets(config.targets)` returns a map. Each adapter file registers itself on import; `index.ts` imports every adapter.

## HTTP target (`src/targets/http.ts`), spec `{ kind: "http", ... }`
- `url: string`, `method = "POST"`, `headers?: Record<string,string>`, `timeoutMs = 60000`.
- `body?: ((c: { input: unknown; caseId: string; prefix?: ChatMessage[] }) => unknown) | Record<string, unknown>`; default `{ input }`. GET sends `input` as query `?input=<json>`.
- `output?: ((json: unknown) => unknown) | string` where a string is a dotted path (`answer`, `data.text`); default: the whole JSON body (text if not JSON).
- Server-side trace: if the JSON body has a field `_hone` (name configurable via `traceField`) shaped `{ messages?, spans?, usage? }`, it is lifted into `TargetOutput`. Alternatively a response header `x-hone-trace` with base64 JSON of the same shape.
- `version?: string | (() => Promise<string>)`; default sha256 of the spec with functions stringified.
- Non-2xx becomes `TargetOutput.error = "HTTP <status>: <body excerpt>"` with `output: null` (never throws; the executor decides).
