# T-605 Branch-point ranking

## Goal
Rank the steps of a failed trace by how likely a fork there changes the outcome, so the fork screen and `hone explain` can suggest where to intervene.

## Design (`src/analysis/branchpoints.ts`)
- `rankBranchPoints(failed: Trial, sibling?: Trial) -> { step: number; score: number; reasons: string[] }[]` sorted by score desc. Signals (each adds to the score with a reason string):
  - a span with `attrs.error` at that step (3)
  - the first divergence from a passing sibling by `alignTraces` (3)
  - a tool result that differs from the sibling's result for the same aligned tool call (2)
  - the last tool call before the final assistant message (1)
  - an assistant message that claims completion without a following tool call (1)
  - messages in the first 20% of the trace get -1 (editing the prompt is a different workflow)
- The fork screen marks the top 3 with `★`; `hone explain` prints "fork candidates: steps 7, 4, 9" with reasons.
