# T-703 Optimize: bandit allocation with a paired verdict

## Goal
Spend a trial budget across named candidates with Thompson sampling, then decide with a paired test instead of trusting the bandit's means.

## Design
- Config hook: `optimize?: Record<string, (config: HoneConfig) => HoneConfig>` (named candidates, same shape as `ablations`; the baseline is the unmodified config and is always an arm named `baseline`).
- `src/correct/optimize.ts`:
  - `optimize(opts)`: arms = `baseline` + candidate names; `BetaBandit(arms, seed)`. Rounds of `batch` trials: `allocate(bandit, batch)` gives counts per arm; for each arm run that many (case, trial) cells chosen round-robin over the cases with the fewest observations for that arm (so every arm eventually covers every case); `bandit.update(arm, pass === true)` per finished trial. Stop when `budget` trials are spent or when the best arm's posterior probability of being best (estimated from 2000 Thompson draws) exceeds `confidence` (default 0.95) and every arm has at least `minPerArm` (default 3) observations.
  - Each arm's trials go in one run per arm (`runConfig` with a plan filtered to the chosen cases); the final verdict uses `compareTargets` over the cases both the best arm and the baseline covered; `"<arm> beats baseline"` only when p < alpha, else `"no measurable effect"`. Report also includes the posterior mean and the spend per arm.
  - Writes `.hone/optimize/<id>.json` in the `CandidatesFile` shape (`kind: "optimize"`, `text` = candidate name, `passAt1` = posterior mean, `lo`/`hi` = Wilson on observed trials, `costUsd` = spend).
- `hone optimize [--budget 60] [--batch 10] [--confidence 0.95] [--alpha 0.05] [--seed n] [--json]`: table of arms (trials, pass rate with CI, P(best), cost), the verdict line, the path written. Exit 2 when `config.optimize` is missing.
