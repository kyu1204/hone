# T-1010 Coding agents: one init wires the skill and the MCP server

## Goal
After `hone init`, Claude Code, Codex or Cursor in that project knows how to evaluate, read a diagnosis, write a change file and run the cycle. e2e's `init` installs its skill into `.agents/skills/` and `.claude/skills/` and registers `e2e mcp` in `.mcp.json` and `.cursor/mcp.json`; its skill is a short router to topic references, and `e2e guide <topic>` prints the same text.

## Design
- `skills/hone/SKILL.md` becomes a router: what hone is in five lines, a table "when you are ... read ...", the workflow for improving a system (measure, read the diagnosis, write one change per hypothesis, run the cycle, report the verdict as printed), and the rules. Topic references under `skills/hone/references/`: `setup.md`, `cases.md`, `sharpening.md` (the change grammar and the cycle), `results.md` (verdicts, the ledger, what not to claim), `steps.md` (the single-step commands), `mcp.md`.
  - Rules the skill must state: never edit a file the baseline runs; one hypothesis per change; do not open the case files to tune against them; `PROMISING` is not an improvement; report the verdict line verbatim.
- `hone guide [topic]` prints the skill or one reference from the installed package.
- `hone init` installs the skill and its references into `.agents/skills/hone/` and `.claude/skills/hone/`, and registers the server as `hone` in `.mcp.json` and, when `.cursor/` exists, `.cursor/mcp.json`, merged into what is there. Re-running refreshes the skill and leaves a current registration untouched. `--no-agents` skips both. `--skills` alone keeps its meaning (install only the skill).
- The registered command is `bunx hone-eval serve mcp`: the bare name `hone` on npm is another package.
- MCP tools: `hone_run` becomes `hone_test`; new `hone_sharpen` (budget, until, max cost) returns the result document; new `hone_guide` returns a topic. The server still returns nothing the CLI would not.
- `hone init` also writes `sharpen/README.md`: three lines on what the directory is for and a commented change.
