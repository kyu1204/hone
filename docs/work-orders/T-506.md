# T-506 Fork screen

## Goal
Pick a step in a trace, edit the prompt or a tool result, re-run from there, and compare the result with the original without leaving the TUI.

## Design (`src/tui/screens/fork.tsx`, running through `correct/fork.ts` from T-701; until it lands, the screen calls `target.resume(prefix, input, ctx)` directly through a `forkTrial` function in `src/tui/forkRunner.ts` that T-701 replaces)
- Step list on the left (messages with index); the current step is the fork point; `enter` opens an editor (`textarea`) for that message's content or, on a tool message, its result; `ctrl+s` saves the edit, `esc` cancels.
- `r` runs the fork: prefix = messages before the fork point plus the edited message; shows a spinner, then the new trial's verdict and scores next to the original; `enter` on the result opens the trace screen; `d` opens the diff screen with original vs fork.
- Forked trials are stored as normal trials with the `forked-from:<trialId>` flag and `trace.meta.forkStep`.
- Branch-point hints: steps that `analysis/branchpoints.ts` (T-605) ranks highest get a `★` marker; before T-605, no marker.
