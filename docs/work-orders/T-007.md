# T-007 Jev System One provider

## Goal
A client for TypeSafe Jev System One used by scorers (T-205), classification (T-602) and reward-hack confirmation (T-202). Behaviour mirrors jgrep's hardened client.

## Facts (as of 2026-10-11, https://docs.typesafe.ai/api)
- `POST https://api.typesafe.ai/v1/systemone`, header `Authorization: Bearer <key>`, body `{ model, state, questions }`.
- `questions` is a map of id to `{ type: "noul", instructions, criteria?: { true, false } } | { type: "choice", instructions, criteria: Record<string, string|null> } | { type: "score", instructions, criteria: string[] }` (choice max 255 options, score 2 to 10 levels).
- Response `{ model, answers: Record<id, { type:"noul", noul:number } | { type:"choice", choice:string, probabilities:Record<string,number>, confidence:number } | { type:"score", score:number, legend:string[], probabilities:number[], confidence:number }>, usage: { input_tokens, output_tokens } }`.
- OpenRouter mirror: `https://openrouter.ai/api/v1/systemone`, model `~typesafe/jev-latest`. Direct model `jev-latest`.
- Price: input $0.042 per 1M tokens, output free.

## API (`src/providers/jev.ts`)
- `resolveJevProvider(env = process.env): { apiKey: string; endpoint: string; model: string }`. Precedence: `TYPESAFE_API_KEY` then `OPENROUTER_API_KEY`; `HONE_JEV_ENDPOINT` overrides the URL (https only, except loopback http); `HONE_JEV_MODEL` overrides the model. Env is read from process env, then `./.env`, then `~/.config/hone/env`, then `~/.config/jgrep/env` (first hit per variable). No key: throw `JevConfigError` naming both variables.
- `class JevClient { constructor(opts: { provider?; fetchImpl?; requestTimeoutMs = 20000; maxRetries = 3; ratePerSec?; concurrency = 4 }); ask(state: unknown, questions: Record<string, JevQuestion>): Promise<JevResult>; }` where `JevResult = { answers; usage; costUsd }`.
- Retries on 408, 429, 5xx and network errors with exponential backoff and jitter; honours `Retry-After`. 401/403 throw `JevAuthError`. 4xx others throw `JevRequestError` with response body excerpt.
- Rate limiter: token bucket when `ratePerSec` set. Concurrency: simple semaphore.
- Helpers: `noul(instructions, criteria?)`, `choice(instructions, options)`, `score(instructions, levels)` build question objects and validate limits (255 options, 2 to 10 levels) locally before sending.
