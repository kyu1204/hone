# T-410 hone power, explain, report

## Goal
Three small commands on top of existing modules.

- `hone power --effect d [--alpha a] [--power p] [--pairing-corr r] [--repeats k] [--icc i --cluster-size s]` prints required pairs; `hone power --n N` prints the minimum detectable effect (T-304).
- `hone explain <trialId>` prints: header (case, target, trial, pass, flags, cost, duration), scores with reasons and evidence, messages with tool calls abbreviated, spans as a tree. `--json` dumps the trial.
- `hone report [--run id] [--out report.html]` writes one self-contained HTML file: summary tiles, case x target matrix, per-cell trial lists with scores and reasons, flags highlighted. No external requests; inline CSS; a tiny inline script for collapsible sections.
