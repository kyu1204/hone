# T-1004 The first five minutes: init, test, sharpen

## Goal
`hone init`, `hone test`, `hone sharpen` work in that order on a fresh project and the README says so in one screen.

## Design
- `hone init`: the generated `hone.config.ts` contains a `sharpen` block for the detected project when there is a text to rewrite, and a commented example otherwise, so `hone sharpen` has something to change without the user reading the docs.
- A sixth example, `examples/sharpen`: a toy help-desk bot steered by a style text and a matching mode, 18 independent cases, nothing passing as written. The setting helps only once the text is rewritten, so the run shows a variant retried on a rewrite. `qa-fn` stays as it is: the other examples have to be green under `hone test --ci`, and this one starts broken on purpose.
- Found by running the example against a real model and fixed here: the account clips long model wording (the ledger keeps it); the split keeps cases that declare the same `cluster` on one side and the confirmation counts a cluster as one unit; an exact sign test is a floor under the paired t test, so a handful of identical improvements is not reported with p = 0.
- README: the config example used helper functions the package does not export; it becomes a config that runs. The quick start is the three commands with real captured output; the command reference shrinks to a link to `docs/cli.md`; "Does it actually improve anything?" states who did what in the two studies (which steps hone ran, which decisions a person made).
- `skills/hone/SKILL.md`, `docs/correction.md`, `docs/README.md`, `docs/concepts.md` follow the three-command surface. `CHANGELOG.md` 0.1.0 lists the surface and `sharpen`.

## TDD steps
1. `src/cli/commands/init.test.ts`: the generated config type-checks and has a `sharpen` block or the commented example.
2. `examples/examples.test.ts`: nothing passes on `examples/sharpen` as written; `hone sharpen` with a stubbed chat ends `PROVEN` with the variant on the rewrite; without a key it ends `NO GAIN` and says rewrites were skipped.
3. `src/correct/sharpen.test.ts`: clusters stay on one side of the split; five held-out improvements are promising and six are proven.
4. Write the docs; `bun scripts/check-links.ts` and the cli-docs staleness test green.
