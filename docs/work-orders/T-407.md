# T-407 hone ablate

## Goal
Measure what each component contributes by running without it and comparing paired.

## Config
`HoneConfig.ablations?: Record<string, (config: HoneConfig) => HoneConfig>`: pure transforms (drop a scorer, swap a target spec, remove an env var from a process target, shorten a prompt).

## CLI
- `hone ablate [name]... [--trials n] [--json]`: runs the baseline config and each named ablation (all when none given) over the same cases and trials, then `compareTargets` baseline vs ablation per case using passAt1.
- Output per ablation: delta with CI, p, verdict ("component helps", "component hurts", "no measurable effect"), cost delta. Sorted by |delta|.
- Each ablation run is a normal run in the store with `summary.ablation = name`.
