# T-405 hone matrix

## Goal
The harness x model view: per target, how often it solves, what it costs per solve, tokens and seconds per solve, timeouts and hacks.

## CLI
- `hone matrix [--run id] [--by model|agent|target] [--json]`.
- Per target (or group by `trace.meta.model` / `trace.meta.agent`): cases, trials, passAt1, pass^3, cost per solved trial ("n/a" when none), tokens per solve, wall ms per solve, timeouts, reward-hack flags, cached share.
- Leaderboard groups from T-303 printed as bands: targets in the same group share a letter.
- Sorted by passAt1 desc, then cost per solve asc.
