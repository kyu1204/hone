# T-1202 `hone try`: one message to the agent, the whole conversation back

DROPPED (the maintainer's call, 2026-10-14): no new command. A coding agent with a shell can call the agent itself; a person can write one case and run `hone test --case`.

## Goal
e2e lets an agent open a page and look before it writes a test. Writing a case for an agent starts the same way: send it something and see what it does.

## Design
- `hone try "<message>" [--target id] [--json]` runs one input through a target, with no cache and no scoring, and prints the conversation: the user's message, each tool call with its arguments, each tool result, the answer, tokens, cost and time. A message that is a JSON object is passed as the input as it is.
- MCP tool `hone_try` with `input` and `target`, returning the same text, so a coding agent can look before it writes cases.
- The skill's `cases` reference says to try the agent before writing cases.
