# T-803 Export OTel GenAI, Docent, JUnit, HTML

## Goal
Get hone results out in the formats other tools read, from one `hone export` command.

## Design (`src/io/export/*.ts`)
- `otel.ts`: `tracesToOtel(trials) -> { resourceSpans: [...] }` following `docs/compat.md` section 3; every attribute string is a constant in `src/io/otelAttrs.ts` (created by T-802, or by this task if T-802 has not landed), with the semconv commit hash recorded in that file. One root `invoke_agent` span per trace (`gen_ai.agent.name` = targetId, `gen_ai.conversation.id` = caseId), child spans from `trace.spans` mapped by kind, `gen_ai.input.messages`/`gen_ai.output.messages` on the root, one `gen_ai.evaluation.result` event per score (`gen_ai.evaluation.name`, `gen_ai.evaluation.score.value`, `gen_ai.evaluation.score.label` pass/fail), `error.type` when `trace.error`. Span and trace ids are deterministic hex from the trial id.
- `docent.ts`: `toAgentRun(trial) -> { id, transcripts: [{ messages }], metadata: { task_id, model, scores, cost_usd, pass, flags } }`; `tracesToDocent(trials)` -> array.
- `junit.ts`: move `junitXml` out of `cli/commands/ci.ts` into `io/export/junit.ts` (ci imports it); accept trials + summary rather than a RunOutcome.
- `html.ts`: move `renderReport` from `cli/commands/report.ts`; `hone report` keeps working as an alias of `hone export html`.
- `hone export otel|docent|junit|html [--run id] [--out path]` (defaults `otel.json`, `docent.json`, `junit.xml`, `report.html`), removing the `not yet available` branch from T-704.
