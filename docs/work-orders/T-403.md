# T-403 hone run

## Goal
The first real command: load config, build the plan, run, print a table, write JSON, exit with a meaningful code. Also the CLI skeleton every later command plugs into.

## CLI skeleton
- `src/cli/args.ts`: tiny parser `parseArgs(argv, spec)` supporting `--flag`, `--key value`, `--key=value`, repeated keys to arrays, `--no-flag`, positionals, `--help`. No dependency.
- `src/cli.ts` becomes a dispatcher: `hone <command> [...]`; unknown command prints usage and exits 2; `--version`.
- `src/cli/commands/run.ts` exports `runCommand(argv, io)` where `io = { stdout(s), stderr(s), cwd, env }` for tests.

## `hone run` behaviour
- Flags: `--target id` (repeatable), `--case id` (repeatable, glob ok), `--tag t`, `--trials n`, `--adaptive`, `--ci-width w`, `--max-trials n`, `--concurrency n`, `--no-cache`, `--max-cost usd`, `--json [path]`, `--quiet`.
- Loads config, cases, targets, scorers; opens `Store` and `Cache` under `config.cacheDir ?? ".hone"`; creates a run; builds the plan; runs the scheduler with the executor; finishes the run with the summary.
- Progress on stderr unless `--quiet`: one line per trial (`✓`/`✗`/`·` case target trial cost).
- Stdout table: rows = cases, columns = targets, cell = `●●●○○ 0.60` (dots for up to 5 trials, then passAt1), footer with pass^3, total cost, tokens per solve, flagged counts. `--json` prints `{ schemaVersion: 1, runId, summary, cells, trialIds }` (or writes it to the path).
- `--max-cost` aborts via the scheduler signal when accumulated cost exceeds the limit; exit code 3.
- Exit codes: 0 gates satisfied (or none), 1 a gate failed (`gates.passHatK`, `gates.passAt1`, `gates.costUsd`), 2 config or usage error, 3 aborted.
