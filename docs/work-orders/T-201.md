# T-201 Deterministic scorers

## Goal
The cheap, objective scorers every domain uses, plus the `Scorer` contract and registry that T-202 to T-207 build on.

## Contract (`src/scorers/scorer.ts`)
```ts
export interface ScoreContext { case: Case; trace: Trace; trial: number; signal?: AbortSignal }
export interface Scorer { readonly name: string; score(ctx: ScoreContext): Promise<Score> | Score; cacheKeyExtra?(): unknown }
export function registerScorerKind(kind: string, factory: (spec: ScorerSpec) => Scorer): void
export function createScorer(spec: ScorerSpec): Scorer       // ScorerSpec.name is the kind; `id` optional label
export function createScorers(specs: ScorerSpec[]): Scorer[]
```
`Score.value` is 0..1, `pass` is boolean for deterministic scorers, `reason` one line, `evidence` an array of small objects (matched text, path, counts).

## Scorers (`src/scorers/deterministic.ts`), kinds and options
- `exact` `{ expected?: unknown, caseField = "expected", normalize?: "trim"|"lower"|"trim-lower"|"json" }`: output equals expected (JSON deep-equal after normalisation).
- `contains` `{ text?: string | string[], caseField?, all = true, ignoreCase = false }`.
- `regex` `{ pattern: string, flags?: string, target = "output" | "files" | "trace" | "stdout", match = "contains" | "not_contains" | "count:N" }` (mirrors plugin eval). `files` searches `artifacts.files` and `artifacts.diff`; `trace` searches the JSON of messages.
- `json-schema` `{ schema: object }`: a small validator supporting `type`, `properties`, `required`, `items`, `enum`, `minimum`, `maximum`, `minLength`, `maxLength`, `pattern`, `additionalProperties: false`; output parsed from a string if needed. No dependency.
- `tool_used` `{ tool: string | string[], all = true, not = false }` over `messages[].tool_calls` and `spans(kind=tool)`.
- `tool_order` `{ tools: string[], strict = false }`: subsequence (or exact sequence when strict) of tool names.
- `step_count` `{ max?: number, min?: number }`: assistant messages with tool calls plus tool spans.
- `cost` `{ maxUsd: number }`, `latency` `{ maxMs: number }` from `usage.costUsd` and `endedAt - startedAt`.
- `file_exists` `{ path: string | string[], workspace?: string }`: checks `artifacts.files` keys, the diff's `+++ b/<path>` headers, and the filesystem when `trace.meta.workspace` or `workspace` is set.
- `test_command` `{ command: string[], cwd?: string, timeoutMs = 300000, passOn = 0 }`: runs the command in `trace.meta.workspace` (or `cwd`); pass when the exit code equals `passOn`; `evidence` carries the last 20 lines of output.
