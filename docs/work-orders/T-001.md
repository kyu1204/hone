# T-001 Repository toolchain

## Goal
A buildable, lintable, testable empty package with CI, so every later task lands with `bun run check` green.

## Decisions
- Package name `hone-eval` (bare `hone` is taken on npm; the `@hone` scope could not be verified). Bin name `hone`. Users import from `"hone-eval"`.
- Bun only: `"engines": { "bun": ">=1.3.14" }`. `"type": "module"`.
- Runtime dependencies: none in this task. Dev dependencies: `typescript`, `oxlint`, `@types/bun`.
- Entry points: `src/cli.ts` (bin) and `src/index.ts` (library). Both may be stubs that print the version.

## Files
- `package.json`: name, version `0.1.0-dev.0`, description, license `Apache-2.0`, repository, bin `{ "hone": "dist/cli.js" }`, files `["dist", "docs", "skills", "README.md", "LICENSE", "NOTICE"]`, scripts: `build` = `bun build src/cli.ts --target=bun --outfile=dist/cli.js && chmod +x dist/cli.js`, `test` = `bun test`, `lint` = `oxlint src`, `typecheck` = `tsc --noEmit`, `check` = `bun run lint && bun run typecheck && bun run test`.
- `tsconfig.json`: strict, `moduleResolution: bundler`, `module: esnext`, `target: esnext`, `jsx: react-jsx`, `types: ["bun-types"]`, `noUncheckedIndexedAccess: true`, `include: ["src", "test"]`.
- `.oxlintrc.json`: default rules plus `correctness: error`.
- `.github/workflows/ci.yml`: on push to main and on pull_request; `oven-sh/setup-bun@v2` with bun-version `latest`; `bun install --frozen-lockfile`; `bun run check`.
- `.gitignore`: add `node_modules/`, `dist/`, `.hone/`.
- `src/index.ts` exports `VERSION` read from package.json; `src/cli.ts` prints `hone <VERSION>` for `--version` and a one-line usage otherwise.

## Acceptance
- `bun run check` exits 0 locally.
- `bun run build` produces `dist/cli.js` and `./dist/cli.js --version` prints the version.
- CI workflow file is valid YAML and runs on the PR (visible green check).
