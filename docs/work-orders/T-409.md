# T-409 hone init

## Goal
Zero-config start: detect what the project is, write a `hone.config.ts` and example cases that run, and store API keys.

## Detection (`src/cli/detect.ts`)
Signals, each adding a target and example cases:
- `.claude/` or `CLAUDE.md`: `process` target `claude-code` with `workspace: "."`, example case "summarise this repository's README in one sentence" with a `regex` scorer.
- `pyproject.toml`/`requirements.txt` mentioning `fastapi` or `flask`: `http` target `http://localhost:8000/ask` with `rag.citations` and `rag.faithfulness`, one YAML case; a comment explains retrieval spans.
- `.mcp.json` or `claude_desktop_config.json`: one `mcp` target per stdio server.
- `package.json` with `ai`, `openai` or `@anthropic-ai/sdk`: `fn` target stub in `evals/target.ts`.
- Nothing: an `fn` target returning the input and one `exact` case, so `hone run` passes out of the box.

## Keys
Prompts for `TYPESAFE_API_KEY` or `OPENROUTER_API_KEY` and `ANTHROPIC_API_KEY`/`OPENAI_API_KEY` (masked, enter to skip); Jev keys are validated with a one-question ping; writes `~/.config/hone/env` (0600). `--yes` skips prompts, `--no-keys` skips the key step.

## Output
`hone.config.ts`, `evals/*.yaml` (and `evals/target.ts` when needed), `.hone/` appended to `.gitignore`, a closing hint. Never overwrites an existing `hone.config.ts` without `--force`.
