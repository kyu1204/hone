# T-1006 Replicate both studies with zero human decisions

## Goal
Evidence that the cycle, not its operator, finds the improvement. This is the acceptance test for T-1003 and T-1005.

## Design
- RAG (`benchmarks/rag-policy-qa`): declare the v1 prompt as `sharpen.text` and retrieval depth as `sharpen.variants`, run `hone sharpen` once with a fixed seed and budget, and report the held-out verdict next to the 2026-10 hand-run result. Needs paid API calls for the generator and the judge.
- Coding agent (`benchmarks/agent-harness`): run `hone sharpen` with patch proposals over the title-only statements and report whether the loop names the statement as the cause. Needs subscription usage for the agent sessions.
- Both write a section into the existing reports under `docs/benchmarks/`, including the cost and every decision the loop made.

## Blocked
Both runs spend money or quota. The maintainer decides the budget before this starts.
