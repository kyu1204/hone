# T-207 Scorer result caching

## Goal
Judge calls are the expensive part. Cache every scorer result by (trace output and the parts of the trace the scorer reads, scorer spec, judge model) so re-scoring with an unchanged scorer never calls a provider.

## Design (`src/scorers/cached.ts`)
- `cachedScorer(scorer: Scorer, cache: Cache, spec: ScorerSpec): Scorer` wraps `score()`.
- Key = `cacheKey({ scorer: spec, extra: scorer.cacheKeyExtra?.(), trace: { output, messages, spans: spans.map(({ startedAt, endedAt, ...rest }) => rest), artifacts, error } })`. Timestamps are excluded on purpose; `usage` is excluded; `case.id`, `case.expected` and `case.rubric` are included.
- Deterministic scorers are cached too (cheap but uniform); `test_command` opts out by returning `cacheKeyExtra() === Symbol.for("no-cache")`.
- `cacheKeyExtra` for Jev and LLM scorers returns the resolved model id so a model change invalidates.
- A cached hit sets `Score.costUsd = 0` and `Score.evidence` gains `{ cached: true }` as its first item.
