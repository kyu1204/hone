# T-205 Jev judge scorers

## Goal
Thin scorers around the Jev client for yes/no checks, rubric levels and classification, with per-step fan-out for trajectories.

## Scorers (`src/scorers/judge/jev.ts`)
- `jev.noul` `{ instructions: string, criteria?, state = "output" | "messages" | "trace" | (ctx) => unknown, threshold = 0.5 }`: `value` = probability, `pass` = value >= threshold.
- `jev.score` `{ instructions, levels: string[], state = "output", passLevel?: number }`: `value` = score / (levels.length - 1); `pass` = score >= passLevel when given, else null; `reason` = legend entry.
- `jev.choice` `{ instructions, options: Record<string, string|null>, state = "output", pass?: string[] }`: `value` = probability of the chosen option, `pass` = chosen in `pass` when given.
- `jev.steps` `{ instructions, threshold = 0.5, aggregate = "min" | "mean" }`: one `noul` per assistant step (message index) asking the instruction about that step with the conversation so far as state; batches up to 256 questions per request; `value` = aggregate, `evidence` = per-step probabilities. This is the trajectory-judge primitive.
- State builders: `output` = `{ input: case.input, expected: case.expected, output: trace.output }`; `messages` = the message list; `trace` = messages + spans summary (tool names, inputs truncated to 500 chars).
- All take an optional `client` (for tests); default `new JevClient()`. Costs go to `Score.costUsd`.
