# T-307 Thompson sampling

## Goal
Allocate trials among candidate variants (prompts, rules, models) toward the ones that look best, for `hone optimize` (T-703).

## API (`src/stats/bandit.ts`)
- `class BetaBandit { constructor(arms: string[], seed?); update(arm, success: boolean); sample(): string; posterior(arm) -> { alpha, beta, mean }; best() -> arm with highest posterior mean; }` with a seeded PRNG and a Beta sampler (Marsaglia-Tsang gamma).
- `allocate(bandit, budget)` draws `budget` arms by Thompson sampling and returns counts per arm.
