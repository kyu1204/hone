# T-006 Event bus

## Goal
One typed event bus that the scheduler, executor and stats emit on, and that CLI, TUI and MCP subscribe to.

## API (`src/core/events.ts`)
- `type HoneEventMap = { "run:start": { runId: string; total: number }; "trial:start": { trialId: string; caseId: string; targetId: string; trial: number }; "trial:done": { trial: Trial; cached: boolean }; "score:done": { trialId: string; score: Score }; "stat:update": { caseId: string; targetId: string; verdict: Verdict }; "case:stopped": { caseId: string; targetId: string; reason: "ci-width"|"max-trials" }; "run:done": { runId: string; summary: Record<string, unknown> }; "log": { level: "debug"|"info"|"warn"|"error"; msg: string } }`.
- `class HoneEvents { on<K>(k, fn): () => void; once<K>(k, fn); off<K>(k, fn); emit<K>(k, payload); iterate<K>(k): AsyncIterable<HoneEventMap[K]> }`. Listener errors are caught and re-emitted as `log` error, never thrown into the emitter.
