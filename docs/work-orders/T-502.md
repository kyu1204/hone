# T-502 Matrix screen

## Goal
The dashboard: cases as rows, targets as columns, each cell showing trial dots and pass@1, coloured by outcome, with sorting and filtering, live-updating in watch mode.

## Design (`src/tui/screens/matrix.tsx`)
- Grid built from `state.cells`; the selected cell is highlighted (inverse). Cell text `●●●○○ 0.60`, `⚑` when a trial carries `reward-hack`, `⏱` for timeouts, `·` when the cell has no trials yet, a spinner frame while a trial is in flight (watch mode: trials with `n` smaller than the plan's trials and the run not finished).
- Keys: `h/j/k/l` and arrows move, `enter` opens the trace screen for the selected cell, `d` opens diff with the cell as side A (second `d` on another cell completes the pair), `s` cycles sort (case id, pass@1 asc, pass@1 desc, cost), `/` opens a filter input (substring on case id or tag), `c` toggles a column summary row (per target pass@1, pass^3, $/solve).
- Wide runs: columns scroll horizontally keeping the selected column visible; rows live in a `scrollbox`.
