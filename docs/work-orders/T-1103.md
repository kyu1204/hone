# T-1103 Benchmark: the cycle on custom agents

## Goal
Measure what `hone sharpen` does for the helpdesk agent in both frameworks, and whether a coding agent with the skill can drive it.

## Design
- Per framework: `hone test` (baseline, 36 cases, 2 trials), then `hone sharpen` in two arms:
  1. **model**: no change files; hone's own rewrites of the system prompt;
  2. **agent**: Codex with the hone skill and one sentence of instruction writes the change files, hone has no key for rewrites.
- Report `docs/benchmarks/custom-agents.md`: baseline by rule, what was tried, the held-out verdict, cost and time, the same for both frameworks, and what did not work.
- Spend: the agent under test calls a model on every trial. Budget set before the run, actual spend in the report.

## Steps
1. Baseline for both frameworks. 2. Model arm. 3. Agent arm with Codex. 4. Write the report from the ledgers.
