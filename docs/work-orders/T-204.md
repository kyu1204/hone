# T-204 Consistency (metamorphic) scorer

## Goal
A label-free scorer: the target should give an equivalent answer when the input is perturbed in meaning-preserving ways.

## Scorer `consistency` (`src/scorers/consistency.ts`) options `{ mutations = ["paraphrase", "reorder", "noise"], n = 2, compare = "exact" | "jev", target: Target, jevThreshold = 0.7 }`
- Mutations are pure functions on string inputs (`src/scorers/mutations.ts`): `paraphrase` applies a fixed table of safe rewrites (contractions, "What is" <-> "Tell me", trailing punctuation, synonym pairs listed in the file), `reorder` swaps clauses around `;` / `, and` / newline, `noise` appends an irrelevant sentence from a fixed list. Non-string inputs: `noise` adds an `_irrelevant` key; other mutations are skipped. Each mutation is deterministic given `(input, index)`.
- The scorer runs the target `n` more times with mutated inputs (through the executor's cache so repeated runs are free), then compares each mutated output with the original: `exact` after trim/lowercase, or `jev` with a `noul` "The two answers convey the same information" over `{ a, b }`.
- `value` = agreeing / n, `pass` = value >= 0.5, `evidence` = per-mutation `{ mutation, input, output, agree }`.
- The scorer needs a target to call: `ScoreContext` gains optional `runTarget(input: unknown): Promise<TargetOutput>` which the executor provides (T-402); tests supply it directly.
