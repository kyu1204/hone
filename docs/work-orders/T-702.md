# T-702 Evolve (GEPA-lite)

## Goal
Propose text changes from reflection on failures, verify each on a minibatch then the full set, keep a Pareto front over pass rate and cost, and say plainly when nothing beat the baseline.

## Design
- Config hook (`src/core/config.ts`): `evolve?: { seed: string; apply: (config: HoneConfig, text: string) => HoneConfig; label?: string }`. `seed` is the mutable text (a system prompt, a rule file, a rubric); `apply` returns the config with that text in place. Nothing else in the config is touched.
- `src/correct/evolve.ts`:
  - Export `runConfig` from `correct/ablation.ts` (already there, make it public) and reuse it for every candidate run.
  - `reflect({ chat, text, failures }) -> { text: string; rationale: string }`: one chat call with the current text and up to 6 failure summaries (`analysis/cluster.summarise`) asking for a revised text as JSON `{ "text": "...", "rationale": "..." }`. Fenced or bare JSON accepted; unparseable reply -> candidate skipped and counted against the budget.
  - `evolve(opts)`: baseline run on all cases -> front = [baseline]. For `budget` iterations: pick a parent from the front (round robin), reflect on its failures, run the child on a minibatch = every case the parent failed plus up to `minibatch` passing cases; if the child's minibatch pass rate is below the parent's on the same cases, discard (record as `rejected: "minibatch"`); otherwise run the full set and add to the front. Pareto: a candidate is dominated when another has pass rate >= and cost <= with at least one strict. Stop early when `maxCost` (USD, all runs together) is reached.
  - Final verdict: paired `compareTargets` of the best front member against the baseline per case; the report says `"<id> beats baseline"` only when p < alpha (default 0.05), otherwise `"no measurable effect"`.
  - Writes `.hone/evolve/<id>.json` in the T-505 `CandidatesFile` shape (`kind: "evolve"`, `pareto`, `parent`, plus `rationale` and `rejected` fields on candidates) and `.hone/evolve/<id>-<candidate>.txt` with each text.
- `hone evolve [--budget 6] [--minibatch 8] [--trials n] [--max-cost usd] [--alpha 0.05] [--seed n] [--json]`: table of candidates (pass@1 with CI, cost, pareto marker, rationale clipped), the verdict line, and the path written. Exit 2 when `config.evolve` is missing.
