# T-404 hone compare

## Goal
A paired comparison between two targets of one run, or the same target across two runs, with significance.

## CLI
- `hone compare <targetA> <targetB> [--run id]` (default latest run) or `hone compare --run A --run B [--target id]`.
- Rows per case: value = passAt1 of the cell (mean over trials) or, with `--scorer name`, the mean score value. Cases missing on either side are dropped and counted.
- Output: mean A, mean B, difference with CI, t, p, McNemar p when binary, cluster-robust CI when cases carry `cluster`, variance reduction from pairing, and a verdict line: "A better", "B better" or "no significant difference" at `--alpha` (default 0.05). `--json` prints the `CompareResult` plus rows.
- Exit code 0 always.
