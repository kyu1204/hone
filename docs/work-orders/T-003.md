# T-003 Config and case loading

## Goal
`defineConfig` API, `hone.config.ts` discovery and loading, case file loading from a glob.

## API
- `src/core/config.ts`: `export function defineConfig(c: HoneConfig): HoneConfig` (identity, typed). `HoneConfig` = `{ targets: Record<string, TargetSpec>; cases: string | string[] | Case[]; trials?: number; adaptive?: { ciWidth: number; maxTrials: number }; scorers: ScorerSpec[]; gates?: GateSpec; concurrency?: number; cacheDir?: string }`. `TargetSpec` and `ScorerSpec` are opaque in this task: `{ kind: string; id?: string; [k: string]: unknown }` and `{ name: string; [k: string]: unknown }`. `GateSpec` = `{ passHatK?: { k: number; min: number }; passAt1?: { min: number }; costUsd?: { max: number }; rewardHack?: "fail"|"warn"|"ignore" }`.
- `loadConfig(cwd = process.cwd()): Promise<{ config: HoneConfig; path: string; hash: string }>`: looks for `hone.config.ts`, `hone.config.js`, `hone.config.mjs` in order, dynamic `import()`, takes `default`. `hash` is sha256 of the file bytes. Missing file throws `ConfigNotFound` with a one-line hint to run `hone init`.
- `loadCases(spec: HoneConfig["cases"], cwd): Promise<Case[]>`: inline array returned as is; string(s) are globs resolved with `Bun.Glob`; `.yaml`/`.yml` parsed with `Bun.YAML.parse`, `.json` with `JSON.parse`, `.jsonl` one case per line. Each file may hold one case object or an array. A case without `id` gets `id` = file stem (plus `#<index>` for arrays). Duplicate ids throw. Every case passes `assertCase` (T-002).
