# T-603 Trace diff as an analysis module

## Goal
Make trajectory alignment a shared analysis primitive and a CLI command, not a TUI-only helper.

## Design
- Move `src/tui/align.ts` to `src/analysis/diffTrace.ts` (same API: `signature`, `alignTraces`); add `divergenceReport(a, b)` -> `{ step, aMessage, bMessage, kind: "missing-in-a"|"missing-in-b"|"different-tool"|"identical" }`. The TUI imports from the new location; the old file is deleted.
- `hone diff <trialA> <trialB> [--json]` prints aligned rows (`A | B` with gap markers) and the divergence report; exit 0.
