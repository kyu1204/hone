# T-401 Plan and scheduler

## Goal
Turn config + cases + targets into trials, run them through a concurrency pool, and in adaptive mode keep sampling the cells whose confidence interval is widest.

## API
- `src/core/plan.ts`: `buildPlan({ config, cases, targets, filter?: { cases?: string[]; targets?: string[]; tags?: string[] } }) -> Plan` where `Plan = { cells: { caseId: string; targetId: string }[]; trials: number; adaptive?: { ciWidth: number; maxTrials: number; minTrials?: number }; concurrency: number }`. Filters match ids exactly or by glob (`Bun.Glob`), tags match any. Defaults: trials 3, concurrency 4.
- `src/core/scheduler.ts`: `runPlan(plan, deps) -> Promise<RunSummary>` with `deps = { runId, execute: (cell, trial) => Promise<Trial>, events: HoneEvents, signal?: AbortSignal, retries = 1 }`.
  - Fixed mode: every cell x trial index is a job; a pool of `plan.concurrency` workers; jobs ordered round-robin across cells so early results cover every cell.
  - Adaptive mode: cells start with `minTrials` (default 2) jobs each; whenever a worker frees, it takes `nextCell(cells, ciWidth)` from `stats/sequential`; emits `case:stopped` when a cell stops; ends when `nextCell` returns undefined.
  - A trial whose trace `error` matches `/timeout|ECONN|fetch failed|exited/` is retried up to `retries` times with the same trial index; the final attempt is kept and `trace.meta.attempts` records the count.
  - After every trial: `stat:update` with `verdictFor(caseId, targetId, outcomes)` for that cell (null passes count as failures).
  - `RunSummary = { runId, cells: Verdict[], totals: { trials, passed, passAt1, costUsd, durationMs, cached, flagged: Record<string, number> }, stoppedEarly: number, aborted: boolean }`.
  - Abort: `signal` stops scheduling new jobs; running ones finish; `aborted: true`.
