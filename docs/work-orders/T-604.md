# T-604 Judge calibration by fault injection

## Goal
Measure what a judge catches: inject silent faults into passing trials, re-score, and report detection rates with intervals, false alarms on clean runs, and kappa against human labels when given.

## Design (`src/analysis/calibrate.ts`)
- Fault injectors, pure functions `(trial, rng) -> Trial | undefined` (undefined when not applicable):
  - rag: `unsupported-claim` appends a plausible sentence that no retrieved chunk supports; `wrong-citation` rewrites one citation id to a chunk that does not contain the claim.
  - qa: `answer-swapped` replaces the output with another passing trial's output for a different case; `negated` flips a number or inserts "not".
  - agent: `verification-removed` deletes the last `tool_call` + `tool` pair whose name matches /test|verify|check|run/i before the final assistant message; `tool-result-swapped` replaces one tool result with the same tool's result from another trial; `premature-done` truncates after the first assistant message that claims completion.
- `calibrate({ trials, scorer, domain, n = 20, seed, labels? }) -> CalibrationFile` (T-505 shape): take up to `n` passing trials, for each fault type inject into each, run the scorer, detection = `pass === false`; clean trials scored again count false alarms; `labels` (`Map<trialId, boolean>`) enable Cohen's kappa between the scorer's pass/fail and the labels on the clean trials.
- `hone calibrate --scorer name [--domain rag|qa|agent] [--run id] [--n 20] [--labels file.csv] [--json]` writes `.hone/analysis/calibration-<scorer>.json` and prints the table.
