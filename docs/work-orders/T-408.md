# T-408 hone ci

## Goal
The merge gate: run, check thresholds per axis, exit non-zero naming the failing axis, leave artifacts CI can archive and a PR comment humans can read.

## CLI
- `hone ci [--baseline run-id] [--junit path] [--comment] [--pr n] [--json path] [run flags...]`.
- Gates from `config.gates` plus `--min-pass-at-1`, `--min-pass-hat-k k:min`, `--max-cost`, `--max-regression delta` (vs baseline passAt1, paired by case).
- Writes `.hone/ci/last.json` (`{ schemaVersion: 1, runId, gates: { name, value, threshold, pass }[], summary }`) and, with `--junit`, JUnit XML with one testcase per case x target (failure message = scorer reasons).
- `--comment` posts a markdown table with `gh pr comment` when `GITHUB_ACTIONS` is set and a PR number is known (`--pr` or `GITHUB_REF`), otherwise prints the markdown to stdout.
- Exit: 0 all gates pass, 1 any gate fails (first failing gate on stderr), 2 usage/config error.
