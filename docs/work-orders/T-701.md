# T-701 Fork as a correction library and CLI

## Goal
Make prefix-pinned re-runs a first-class correction primitive: a library module every caller (TUI, CLI, MCP, evolve) shares, plus `hone fork`.

## Design
- Move `src/tui/forkRunner.ts` to `src/correct/fork.ts` (same `forkTrial(req)` API and `ForkRequest`); the TUI imports from the new location and the old file is deleted. Add `loadForkDeps(cwd)` -> `{ targets, scorers, caseInputs }` extracted from the tui command so `hone tui`, `hone fork` and later `hone serve mcp` build the same dependencies.
- `hone fork <trialId> --step n (--content "text" | --file path) [--json]`: replaces message `n` of the trial with the given content (role kept from the original message; a tool message keeps its `tool_call_id` and `name`), re-runs via `forkTrial`, prints the forked trial id, the verdict change (`FAIL -> PASS`), scores, and the `divergenceReport` rows that are not identical. Exit 0 when the fork ran (whatever the verdict), 2 on usage or missing config/trial.
- Without `--step`, print the fork candidates from T-605 and exit 0 (so `hone fork <id>` alone is useful).
