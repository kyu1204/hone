# T-008 LLM chat provider

## Goal
A minimal chat client for generative judges (T-206), taxonomy induction (T-602) and evolve (T-702). Two wire formats: OpenAI-compatible and Anthropic Messages.

## API (`src/providers/llm.ts`)
- `resolveLlmProvider(env): { kind: "openai"|"anthropic"; apiKey: string; baseUrl: string; model: string }`. Precedence: `HONE_LLM_PROVIDER` if set; else `ANTHROPIC_API_KEY` present means anthropic; else `OPENAI_API_KEY` means openai with `OPENAI_BASE_URL` override (default `https://api.openai.com/v1`); `HONE_LLM_MODEL` overrides model. Defaults: anthropic `claude-sonnet-5-5`, openai `gpt-5-mini`. Same env file lookup as T-007. No key throws `LlmConfigError`.
- `chat(req: { messages: ChatMessage[]; temperature?: number; maxTokens?: number; json?: boolean; system?: string }, opts?: { provider?; fetchImpl?; timeoutMs = 60000; maxRetries = 2 }): Promise<{ text: string; usage: Usage; model: string; raw: unknown }>`.
- Anthropic: `POST {baseUrl}/v1/messages` with `anthropic-version: 2023-06-01`; system goes in `system`; tool messages are not supported in this task (throw). OpenAI: `POST {baseUrl}/chat/completions`; `json: true` sets `response_format: { type: "json_object" }`.
- Cost table `src/providers/pricing.ts`: `{ [model]: { inputPerM: number; outputPerM: number } }` for the two defaults plus `gpt-5`, `claude-opus-5-5`, `claude-haiku-5-5`; unknown model costs 0 and the result carries `meta.unknownPricing = true`.
- Retries and errors as in T-007 (`LlmAuthError`, `LlmRequestError`).
