# T-301 Intervals and pass^k

## Goal
The first statistics module: Wilson and CLT intervals, bootstrap, and the pass@k / pass^k estimators, matching `test/fixtures/stats-vectors.json` (generated 2026-10-12 from errorbars 0.2.4, scipy and statsmodels).

## API (`src/stats/interval.ts`, `src/stats/passk.ts`, `src/stats/dist.ts`)
- `dist.ts`: `zForConfidence(c)`, `tForConfidence(c, dof)`, `tTwoSidedP(t, dof)`, `regularizedIncompleteBeta(a, b, x)` (continued fraction, as errorbars does), `normalCdf`, `normalQuantile` (Acklam or Wichura AS241). Match the `dist` vectors to 1e-9.
- `interval.ts`: `MeanEstimate = { mean, se, lo, hi, confidence, method, n }`. `wilsonCi(successes, n, confidence = 0.95)`, `meanCiClt(values, confidence)` (t-based like errorbars: check the vector), `bootstrapCi(values, { confidence, nBoot = 2000, seed })` with a seeded PRNG (mulberry32); bootstrap is checked for shape and for containing the mean, not for exact numbers.
- `passk.ts`: `passAtK(n, c, k)` = `1 - C(n-c, k) / C(n, k)`, `passHatK(n, c, k)` = `C(c, k) / C(n, k)`, both unbiased estimators from tau-bench; `logChoose` to stay finite for large n. `verdictFor(outcomes: boolean[], ks = [1, 2, 3, 5])` returns a `Verdict` (types.ts) with `passAt1`, `passHatK` map and a Wilson `ci`.
