# T-503 Trace viewer

## Goal
Read one trial without leaving the terminal: scores, then messages and spans, with tool calls expanded on demand, a retrieval panel for RAG traces, and search.

## Design (`src/tui/screens/trace.tsx`)
- Header: case, target, trial `#n` of `N` (`[`/`]` switch trials of the same cell), verdict, flags, cost, duration, model.
- Left pane (60%): a `scrollbox` of entries: each score (`✓/✗/?` scorer value reason, `e` expands evidence), then each message (role badge, content wrapped, tool calls as `name(args)` collapsed; `enter` on a message expands the full content and tool results), then spans as an indented tree with durations.
- Right pane (40%): context for the current entry: for a tool call, its arguments and result; for a retrieval span, the retrieved documents (id, score, text excerpt) and which ones the output cites (from `rag.citations` evidence when present); for a score, its evidence.
- Keys: `j/k` move entry, `enter` expand/collapse, `e` evidence, `/` search (highlights matches, `n` next), `y` copies the trial id to the clipboard via OSC 52, `f` jumps to the fork screen at the current message, `esc` back to the matrix.
- Long content is virtualised: only visible entries render their full text; others render one line.
