# T-801 Import Claude Code sessions

## Goal
`hone init && hone` shows the user's existing Claude Code sessions in the matrix: each session becomes a case plus a trace, with no run needed.

## Facts (read from real sessions on 2026-10-12)
- Files: `~/.claude/projects/<cwd with / replaced by ->/<sessionId>.jsonl`, one JSON record per line.
- Record `type`s seen: `user`, `assistant`, `system`, `attachment`, `file-history-snapshot`, `cost-state`, `last-prompt`, `mode`, `permission-mode`, `atis-latch`, plus `summary`/`progress` in other sessions. Only `user`, `assistant` and `cost-state` matter; unknown types are skipped.
- `user`/`assistant` records: `uuid`, `parentUuid`, `sessionId`, `timestamp`, `cwd`, `gitBranch`, `version`, `isSidechain`, `isMeta?`, and `message` in Anthropic shape: `role`, `content` (string, or blocks `text` | `tool_use {id,name,input}` | `tool_result {tool_use_id, content, is_error}`), assistant also `model`, `usage { input_tokens, output_tokens, cache_read_input_tokens, cache_creation_input_tokens }`, `stop_reason`.
- `cost-state`: `totalCostUSD`, `totalDuration`, `modelUsage`.
- A human prompt is a `user` record whose `content` is a string (or text blocks) with `isMeta` falsy and `isSidechain` falsy; tool results are `user` records whose content is `tool_result` blocks.

## Design (`src/io/import/claudeCode.ts`)
- `parseSession(text) -> SessionImport | undefined` (undefined when no human prompt): reuse the block conversion from `targets/parsers/claudeCode.ts` by exporting its record handler (`recordsToParsed(records)`), so tool_use/tool_result pairing, spans and usage are one code path. Add session fields to `trace.meta`: `sessionId`, `cwd`, `gitBranch`, `claudeVersion`, `model`, `turns` (human prompts count). `usage.costUsd` from `cost-state.totalCostUSD` when present. `artifacts.diff` synthesised from `Edit` tool inputs (`--- <file>`, `- old_string`, `+ new_string` lines) and `artifacts.files` from `Write` inputs (`file_path` -> `content`), capped at 200 KB total.
- Case: `id` = first 8 chars of the session id, `input` = first human prompt text, `tags: ["claude-code", gitBranch?]`, `meta: { sessionId, cwd, startedAt }`. Trial: `pass: null`, `scores: []`, `flags: []`, `trace.targetId = "claude-code"`, `trace.trial = 0`, `trace.caseId = case.id`.
- `importClaudeSessions({ dir?, files?, limit?, since? })` finds `*.jsonl` (newest first), parses each, skips sessions without a human prompt, returns `{ cases, trials, skipped }`.
- `hone import claude-code [path...] [--project dir] [--limit n] [--since 2026-10-01] [--cases cases.jsonl] [--json]`: path = session files or a directory; default `~/.claude/projects/<dashed io.cwd>`. Creates one run (`targets: ["claude-code"]`, `summary.imported = "claude-code"`), saves every trial, optionally writes the cases as JSONL (`--cases`), prints a table (case id, branch, turns, tools, cost, first prompt clipped). `hone import` is the new command group; other kinds arrive with T-802 and answer `not yet available` until then.
