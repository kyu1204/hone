# T-102 Function target

## Goal
Call a TypeScript function as a Target, with a small builder so the function can record spans, messages and usage without touching the Trace type.

## Spec `{ kind: "fn", fn, version? }`
- `fn: (input: unknown, ctx: FnContext) => Promise<unknown | TargetOutput> | unknown | TargetOutput`.
- `FnContext` (`src/targets/fn.ts`): `caseId`, `trial`, `prefix?`, `signal?`, plus a recorder:
  - `span<T>(kind: SpanKind, name: string, body: (s: SpanHandle) => Promise<T> | T): Promise<T>` records start/end, `s.input(x)`, `s.output(x)`, `s.attr(k, v)`; nested spans get `parentId`; a thrown error ends the span with `attrs.error` and rethrows.
  - `message(m: ChatMessage)`, `usage(partial: Partial<Usage>)` (accumulates).
- If `fn` returns a plain value it becomes `output`; if it returns an object with an `output` key and any of `messages|spans|usage|artifacts`, it is treated as `TargetOutput` and merged with the recorder (recorder spans first).
- `version` default: sha256 of `fn.toString()`.
