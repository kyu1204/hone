# T-002 Core data model

## Goal
Define the v0.1.0 data model as TypeScript types in `src/core/types.ts`, plus runtime guards that reject malformed traces at trust boundaries (importers, HTTP targets).

## Types (exact names)
- `ChatMessage` = `{ role: "system"|"user"|"assistant"|"tool"; content: string | ContentPart[]; tool_calls?: ToolCall[]; tool_call_id?: string; name?: string }` (OpenAI/Docent compatible). `ToolCall` = `{ id: string; type: "function"; function: { name: string; arguments: string } }`. `ContentPart` = `{ type: "text"; text: string } | { type: "image_url"; image_url: { url: string } }`.
- `Span` = `{ id: string; parentId?: string; kind: "llm"|"tool"|"retrieval"|"agent"|"custom"; name: string; startedAt: string; endedAt?: string; input?: unknown; output?: unknown; attrs?: Record<string, unknown> }`.
- `Usage` = `{ inputTokens: number; outputTokens: number; costUsd: number }`.
- `Trace` = `{ id: string; caseId: string; targetId: string; trial: number; startedAt: string; endedAt: string; messages: ChatMessage[]; spans: Span[]; output: unknown; artifacts?: { diff?: string; files?: Record<string,string>; stdout?: string; stderr?: string }; usage: Usage; error?: string; meta?: Record<string, unknown> }`.
- `Case` = `{ id: string; input: unknown; expected?: unknown; rubric?: string; tags?: string[]; cluster?: string; meta?: Record<string, unknown> }`.
- `Score` = `{ scorer: string; value: number; pass: boolean | null; reason?: string; evidence?: unknown[]; costUsd?: number }` with `value` in [0,1].
- `TrialFlag` = `"reward-hack"|"cached"|"timeout"|\`forked-from:${string}\``.
- `Trial` = `{ id: string; runId: string; trace: Trace; scores: Score[]; flags: TrialFlag[]; pass: boolean | null; costUsd: number }`.
- `Run` = `{ id: string; createdAt: string; configHash: string; targets: string[]; caseIds: string[]; summary?: Record<string, unknown> }`.
- `FailureCode` = `{ code: string; axis: "system"|"role"|"domain"; definition: string; evidencePatterns: string[] }`.
- `Verdict` = `{ caseId: string; targetId: string; n: number; passes: number; passAt1: number; passHatK: Record<number, number>; ci: [number, number]; noise?: number }`.

## Guards
`assertTrace(x: unknown): asserts x is Trace`, `isTrace(x): x is Trace`, `assertCase`, `isCase`. Hand-written, no schema library. A guard error message names the first failing path (`trace.messages[2].role`).
