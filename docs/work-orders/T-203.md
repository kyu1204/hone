# T-203 RAG scorers

## Goal
Score retrieval-augmented answers in three layers: retrieval, grounding, citations.

## Retrieval spans
Scorers read retrieved documents from spans with `kind: "retrieval"`: each `span.output` is an array of `{ id?, text?, content?, score? }` or strings; a document id is `id` or the array index as a string.

## Scorers (`src/scorers/rag.ts`)
- `rag.context_recall` `{ caseField = "expected.chunks" }`: fraction of expected chunk ids present in retrieved ids. `rag.context_precision`: fraction of retrieved ids that are expected.
- `rag.citations` `{ pattern = "\\[(c?\\d+|[a-z0-9_-]+)\\]" }`: every citation marker in the output resolves to a retrieved document id; `value` = resolved / total, `pass` = all resolved and at least one citation. Evidence lists unresolved markers.
- `rag.faithfulness` `{ judge = "jev", maxClaims = 20 }`: split the output into claims (sentences, trimmed, dropping ones shorter than 15 chars), ask Jev one `noul` per claim with state `{ context: retrieved texts, claim }` and instructions "The claim is fully supported by the context"; `value` = mean probability, `pass` = min probability >= 0.5; `evidence` = per-claim probabilities. Requests batch up to 256 claims (T-009 decision).
- `rag.answer_relevance` `{ judge = "jev" }`: one `score` question with levels ["irrelevant", "partially relevant", "relevant", "directly answers"] over `{ question: case.input, answer: output }`; `value` = score / 3.
