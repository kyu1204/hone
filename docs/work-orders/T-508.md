# T-508 hone serve ssh

## Goal
Share a live, read-only view of the dashboard: `hone serve ssh --port 2222` serves the TUI to anyone who connects with `ssh -p 2222 host`.

## Design
- `@opentui/ssh` (same 0.6.0 version) serves a renderer per connection; each session mounts the same `App` in watch mode with `readOnly: true` (fork, edits and quit are disabled; `q` disconnects).
- Options: `--port` (default 2222), `--host-key` (path; generated once under `~/.config/hone/ssh_host_key` if absent), `--run` (pin a run instead of following the latest), `--password` (optional shared secret; without it, no auth, intended for demos on trusted networks).
- Prints the connect command on start; logs connections and disconnections.
