# T-306 Item response theory (2PL) and noise

## Goal
Estimate case difficulty and discrimination from accumulated results so adaptive runs order cases by information, and flag cases whose outcomes are noise.

## API (`src/stats/irt.ts`)
- Input: a matrix of outcomes `rows: { targetId, caseId, pass: boolean }[]` (trials are averaged per cell to a probability, or expanded; use the mean).
- `fit2pl(rows, { iterations = 200, lr = 0.05, prior = 1 })` -> `{ targets: Record<targetId, { ability }>, cases: Record<caseId, { difficulty, discrimination }>, logLik }`. Joint maximum a posteriori by gradient ascent with N(0, prior) priors on ability and difficulty and a log-normal prior on discrimination; abilities centred to mean 0 each iteration for identifiability.
- `fisherInformation(ability, item)` = `a^2 p (1-p)`; `orderCasesByInformation(fit, targetId)` -> caseIds sorted by information descending.
- `noiseOf(cell: { successes, n })` = within-cell variance `p(1-p)`; `caseNoise(rows)` -> per case the mean within-cell variance; cases with discrimination below 0.2 and all-pass or all-fail are tagged `regressionOnly`.
