# T-105 MCP server target

## Goal
Evaluate a single tool of a stdio MCP server as a Target.

## Spec `{ kind: "mcp", command: string[], tool: string, args?: (input) => Record<string, unknown>, env?, cwd?, timeoutMs = 60000 }`
- Spawn the server once per Target. JSON-RPC 2.0 over newline-delimited stdio. Handshake: `initialize` (protocolVersion `2025-06-18`, capabilities `{}`, clientInfo `{ name: "hone", version }`) then `notifications/initialized`. Then `tools/call` with `{ name: tool, arguments: args(input) ?? input }`.
- `output`: if every content item is `text`, the joined text (JSON-parsed when it parses); otherwise the raw `content` array. `isError: true` becomes `TargetOutput.error`. `structuredContent` wins over text when present.
- One `tool` span per call with `input` = arguments and `output` = result; message list is `[user(json args), tool(result)]` so scorers that look at messages still work.
- `version()`: sha256 of `command` plus the server's `serverInfo` from `initialize`.
- Crash: restart on next call; `close()` sends nothing, just kills.
